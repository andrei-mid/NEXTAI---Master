# financials agent

**Owner:** `@role-3-official-agents` · **Status:** implemented

**Component:** `financials` (weight 20, PROPOSAL) · **Source:** `anaf_bilant` (OFFICIAL, last 5 years, 1 req/s)

Extracts per year (by `val_den_indicator` label, never by code): turnover, net profit, average employees, total debts, equity, share capital. All thresholds are in [`config.yaml`](config.yaml) (PROPOSAL).

| rule_id | Severity (PROPOSAL) | Condition |
|---|---|---|
| FIN-NET-ASSETS-01 | high | equity < ½ share capital (latest filed year) |
| FIN-REVENUE-JUMP-01 | medium | turnover +300% year over year (base ≥ 100k RON) |
| FIN-HEADCOUNT-01 | medium | turnover per employee > 5× the CAEN-division average (averages are PROPOSAL placeholders, confidence 0.8) |
| FIN-LOSS-TREND-01 | medium | net loss in ≥ 2 consecutive years |
| FIN-DEBT-RISE-01 | medium | debts +50% over the last 3 filed years while turnover grew ≤ 10% (or fell) |
| FIN-REVENUE-DECLINE-01 | medium | turnover −25% over the last 3 filed years *(addition to the brief)* |
| FIN-NO-FILING-01 | medium | ANAF answered but nothing filed for the latest expected year *(addition to the brief)* |

**Failure handling:** a year ANAF can't be read for → `anaf_bilant` in `sources_failed` → PARTIAL (UNAVAILABLE if no year could be read). An empty statement (`"i": []`) means "not filed", which is a fact and is not treated as zero.

**Demo:** Zephyria → NET-ASSETS (high), REVENUE-JUMP (+415.8%), HEADCOUNT (9.3M RON/employee). Brunaldo → REVENUE-DECLINE (−47.8%), LOSS-TREND (2023–2025). Aurora → nothing. The API fixtures are generated by running this agent (`fixtures/tools/build_fixtures.py`), and `tests/test_agent.py` checks they match.

**Files:** `agent.py` (flow + claims), `rules.py` (pure checks + config model), `config.yaml` (thresholds, CAEN averages), `tests/`.
