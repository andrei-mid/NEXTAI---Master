# fixtures/

**Owner:** `@role-6-frontend-demo`. Data for `FIXTURE_MODE=1`: every adapter, agent, test and the frontend work with **no network and no other teammate's code finished**.

Everything here is generated by `make fixtures` (`fixtures/tools/build_fixtures.py`). **Edit the facts in that script, not the JSON**: the generator wipes and rewrites `companies/` and `sources/`. `make fixtures-check` enforces the rules below.

## Fictional data rules

- Every fictional record carries `"fictional": true` (XML/CSV: a `fictional: true` marker).
- Web URLs use the reserved `.example` domain.
- Trade-register numbers use county code **J99** (doesn't exist).
- CUIs are in the 99000xxx range (fillers: 99001xxx) with a **deliberately invalid check digit**, so they can never match a real company. They are accepted only with `FIXTURE_MODE=1` (whitelist in `verifirm/core/cui.py`).
- **DEDEMAN SRL (2816464) is real.** No figures are committed for it. It's fetched live at demo time (see its README).
